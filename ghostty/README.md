# Ghostty 設定

Ghosttyターミナルエミュレータの設定ファイルです。

## 設定内容

### テーマ設定
- **テーマ**: catppuccin-macchiato
- 暗色系の美しいカラーテーマを使用

### フォント設定
- **フォントファミリー**: HackGen Console NF
- **フォントサイズ**: 16pt
- **フォント機能**: 合字（ligature）を無効化
  - `-calt`: 文脈的代替を無効
  - `-dlig`: 任意の合字を無効
  - `-liga`: 標準的な合字を無効
- **フォント太字化**: 有効（視認性向上）
- **セル高さ調整**: +2（行間を広げて読みやすく）

### ウィンドウ設定
- **タイトルバー**: 透明スタイル（macOS）
- **ウィンドウシャドウ**: 無効（よりクリーンな見た目）
- **パディング**: バランス調整あり、X/Y共に0
- **背景**: 半透明（透明度65%）+ ブラー効果（半径20px）
- **ウィンドウテーマ**: ghostty

### カーソル設定
- **カーソルスタイル**: ブロック型
- **カーソル点滅**: 無効（集中力向上）

### その他設定
- **タイピング中マウス非表示**: 有効

### ターミナル設定
- **TERM環境変数**: xterm-256color

## ファイル構成

```
ghostty/
├── config          # Ghostty設定ファイル
└── README.md       # このファイル
```

## 使用方法

このdotfilesリポジトリのルートディレクトリで `install.sh` スクリプトを実行してください。

```bash
./install.sh
```

インストールスクリプトにより、設定ファイルが自動的に適切な場所（`~/Library/Application Support/com.mitchellh.ghostty/config`）にシンボリックリンクされます。
